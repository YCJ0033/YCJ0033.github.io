# 안녕하세요! 윤채준입니다.

국립부경대학교 컴퓨터공학 전공 학생으로, 프로그래밍과 소프트웨어 개발을 공부하고 있습니다.

이 웹사이트는 대학 생활에서 학습한 내용과 프로젝트 경험을 정리하고, 개발 역량을 기록하기 위해 만들었습니다.

## 전공 및 관심 분야

- **전공:** 컴퓨터공학
- **소속:** 국립부경대학교
- **관심 분야:** 소프트웨어 개발, 데이터 분석, 정보보안
- **개발 도구:** Python, Git, GitHub, VS Code

## 학습 및 프로젝트

### 1. 오픈소스소프트웨어
Git과 GitHub을 활용한 버전 관리 및 협업 방법을 학습하고 있습니다. Jekyll과 GitHub Pages를 이용해 개인 웹사이트를 제작했습니다.

### 2. 자료구조
Python을 활용하여 다양한 자료구조와 알고리즘의 기본 원리를 학습하고 있습니다.

### 3. 정보보호론
정보보호의 기본 개념과 암호화 기술을 학습하며 관련 프로그램을 구현하고 있습니다.

## 앞으로의 목표

다양한 개발 경험을 쌓으며 컴퓨터공학 분야의 실무 역량을 키우는 것이 목표입니다. 앞으로 진행하는 프로젝트와 학습 결과를 이 웹사이트에 지속적으로 기록할 계획입니다.
