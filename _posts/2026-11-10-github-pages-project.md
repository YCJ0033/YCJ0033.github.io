# GitHub Pages를 활용한 개인 웹페이지 제작

이번 오픈소스소프트웨어 수업에서는 GitHub Pages와 Jekyll을 활용하여 개인 웹페이지를 제작하는 실습을 진행했다.

## 1. GitHub Pages란?

GitHub Pages는 GitHub 저장소에 있는 파일을 이용하여 정적 웹사이트를 만들고 배포할 수 있는 서비스이다. 별도의 웹 서버를 직접 운영하지 않아도 개인 웹사이트를 공개할 수 있다는 특징이 있다.

## 2. 개인 웹페이지 제작 과정

먼저 Ruby와 Jekyll을 설치하고 로컬 환경에서 기본 웹페이지가 정상적으로 실행되는지 확인했다.

이후 GitHub에서 Academic Pages 테마를 선택하고, 내 계정에 `YCJ0033.github.io` 저장소를 생성했다.

GitHub Actions를 설정하여 웹페이지가 자동으로 빌드되고 배포되도록 구성했다.

마지막으로 `_config.yml` 파일을 수정하여 사이트 제목, 이름, 소속, 자기소개 및 프로필 이미지를 변경했다.

## 3. 실습을 통해 학습한 내용

이번 실습을 통해 GitHub Pages와 Jekyll이 어떻게 연결되는지 이해할 수 있었다.

또한 GitHub 저장소에 변경 사항을 커밋하면 GitHub Actions가 자동으로 실행되어 웹사이트에 수정 내용이 반영된다는 점을 확인했다.

## 4. 마무리

이번 실습을 통해 개인 웹페이지를 직접 제작하고 배포하는 과정을 경험했다. 앞으로는 전공 수업에서 진행한 프로젝트와 학습 내용을 웹사이트에 추가하여 포트폴리오로 활용할 계획이다.
